# RAXON League — Documentación del Sistema

## Descripción
Sistema de gestión y sitio web para **RAXON League**, construido para escalabilidad en eSports.

- **Frontend:** HTML5, CSS3 vanilla, JavaScript ES6+ (Alojado en GitHub Pages).
- **Backend / Database:** Supabase (PostgreSQL, Auth, Storage, Policies RLS).

## Instrucciones de Instalación Local
1. Clona este repositorio o descarga los archivos.
2. Sirve la carpeta raíz con cualquier servidor HTTP local (ej: `npx serve .`).
3. Ajusta las claves de conexión en `js/supabase-client.js`.
